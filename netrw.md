Visor de archivos nativo de vim 
Comandos para usarlo:
```
R → renombrar archivo

% → crear nuevo archivo

d → crear directorio

D → borrar archivo

Enter → abrir archivo
```
Para mover archivos
```
mf (marca el archivo)
mm (mueve el archivo marcado a un directorio)
mc (hace copia del archivo marcado en el destino)
```
